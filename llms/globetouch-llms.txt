# Globetouch (now Airlinq)

> Global mobile and IoT connectivity provider, founded 2010, headquartered in San Ramon,
> California. Rebranded to Airlinq in February 2020; globetouch.com 301-redirects to
> www.airlinq.com. Sells SIM / soft-SIM / eSIM provisioning and connectivity-lifecycle
> management to mobile network operators, MVNOs and IoT enterprises.

## Status of the machine-readable surface

Globetouch/Airlinq markets APIs as a product capability but publishes **no** public API
contract. As of 2026-08-22 there is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card reachable without
a sales conversation. Access is via the contact form only. Do not assume an endpoint;
none is published.

## Products

- [Mobilinq](https://www.airlinq.com/mobilinq/): IoT connectivity and application management
  platform for operators — activation, suspension, diagnostics and retirement across the
  device lifecycle. Marketed as integrating with operator BSS/OSS "through a comprehensive
  API library" for provisioning, rating, billing and lifecycle automation.
- [Autolinq](https://www.airlinq.com/autolinq/): connected-vehicle ecosystem platform.
- [Utilinq](https://www.airlinq.com/utilinq/): connectivity for electric, gas and water
  utilities; marketed as offering "a single, comprehensive API" for integration with
  operational, billing and analytics systems.
- [Marketlinq](https://www.airlinq.com/marketlinq/): operator-branded private-5G and IoT
  marketplace and dashboard for discovering, testing and deploying connectivity solutions.
- [Platform](https://www.airlinq.com/platform/): the shared platform overview.
